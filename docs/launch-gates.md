# Launch Gates

Production launch remains blocked until each gate has an accountable owner, evidence, and recorded approval.

| Gate | Required evidence |
|---|---|
| Operator and professional identity | Verified entity, professional status, credentials, authorizations, and approved disclosures |
| Jurisdictions | Authorized service jurisdictions, target user locations, limitations, and routing rules |
| Service model | Approved services, engagement formation, conflicts/eligibility, fees, cancellations, refunds, no-shows, records, and support |
| Privacy | Data map, purposes, notices, consent, vendors, locations, retention, deletion, user rights, and incident obligations |
| Security | Threat model, access, encryption, secrets, monitoring, vulnerability management, backup, recovery, and incident response |
| AI governance | Approved topics, jurisdictions, sources, permissions, provider, evaluation, prohibited uses, retention, escalation, monitoring, and kill switch |
| Commerce | Approved products, files, ownership/licenses, prices, taxes, delivery, refunds, chargebacks, and provider |
| Localization | Authoritative language and qualified review of French and Chinese meaning-sensitive content |
| Vendors | Privacy, security, contractual, availability, location, subprocessor, deletion, and exit review |
| Testing | Functional, authorization, privacy, security, accessibility, localization, provider, AI, recovery, and operational evidence |

The browser administration view is a local tracker only. Selecting "Approved locally" does not create a valid organizational approval.
